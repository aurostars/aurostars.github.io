# Company Marks

These assets reuse the repository's existing artwork and the user-provided reference. No raster source was enlarged.

- `bytedance-color.svg`: user-provided 24 x 24 color ByteDance graphic, used directly without redrawing or rasterization.
- `bytedance.svg`: superseded square graphic retained as an unused historical asset.
- `iflytek.svg`: graphic path extracted from the existing vector wordmark.
- `meituan.png`: 409 x 400 graphic extracted from the 1130 x 400 PNG in commit `05d4e2f`.
- `bosszhipin.png`: original 115 x 115 PNG from commit `05d4e2f`, replacing the 16 x 16 favicon.
- `pacific-securities.png`: 108 x 122 graphic extracted from the original 537 x 122 PNG in commit `05d4e2f`.
- `drc-big-data-hd.png`: original 640 x 640 company logo from the institute's Guopin recruiting profile, converted from JPEG to PNG without resizing. This profile uses a red triangular mark, different from the user's reference and the B4D mark on the parent group's website.
  - Company profile: https://zp.iguopin.com/detail/companyDetail?companyId=10685394459272080&id=80195686645114332
  - Public company metadata: https://gp-api.iguopin.com/api/company/index/v1/simple-info?company_id=10685394459272080
  - Original image: https://iguopin-company.oss-cn-beijing.aliyuncs.com/10685394459272080/logo/20230612/4aa0752a971e262ea2b12203caf999af.jpg
  - Identity cross-check: company name, 2020-06-23 founding date, and parent-group website match the institute. Retrieved 2026-09-15.

Company slots are 48 x 48 CSS pixels with contained images and inner padding. School emblems remain the existing vector assets.
