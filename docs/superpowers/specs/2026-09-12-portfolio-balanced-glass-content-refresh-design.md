目标受众：快速浏览候选人经历与独立项目的招聘者

## 1. 目标与范围

本轮在现有紧凑档案式主页上做定向升级，不恢复大型 Hero，不改变单页信息架构，也不新增目录导航。

目标：

1. 将教育经历与实习经历调整为左右两栏。
2. 增加字节跳动实习经历，并以官方品牌色公司 Logo 提升辨识度。
3. 将视觉升级为 B1 平衡通透风格，丰富层次但避免全页玻璃化。
4. 修正项目详情弹窗偏左问题，使其严格相对视口居中。
5. 简化项目卡片操作提示，并把项目详情中的能力描述替换为 README 可验证的功能清单。
6. 收敛详情链接与秋招网申助手截图。

不在本轮范围内：

- 新增页面、路由或目录导航。
- 增加大型 Hero、头像、职业标签或个人口号。
- 修改项目 URL 或 GitHub 仓库地址。
- 展示 README 中的规划项或无法验证的能力。

## 2. 设计方向

### 2.1 设计判断

这是一个面向招聘者的个人作品集。视觉采用明亮、通透、具备产品感但不呈现标准 SaaS 官网气质的表达。

- 设计模式：现有页面的定向演进，不做框架或信息架构重写。
- 设计变化度：7。
- 动效强度：5。
- 信息密度：6。
- 主题：默认明亮 B1 主题，系统深色模式自动适配。

### 2.2 B1 平衡通透

- 页面背景：冰白与极淡雾蓝环境色，加入非常轻的固定颗粒或微纹理。
- 强调色：全页锁定为一种低饱和电蓝。
- 身份栏与履历区：低透明度磨砂表面、1px 内高光边框、柔和蓝灰阴影。
- 项目卡片：接近实体白色，避免截图与背景混在一起。
- 详情弹窗：页面中玻璃层级最明显的组件，但仍保证文字与截图对比度。
- 圆角规则：主要容器与弹窗 16px，内部图片框 12px，按钮可使用全圆角；不混用其他圆角尺度。
- 字体：延续 Geist 本地字体，不增加第三方字体依赖。

明确禁止：

- 紫色 AI 光效、渐变文字、漂浮球体、霓虹描边。
- 大型头像、头像占位或人物图像。
- 大型 Hero、职业标签和个人口号。
- 为装饰而添加的编号、状态点或无意义标签。

## 7. 项目详情弹窗

### 7.1 居中与尺寸

- 继续使用原生 `<dialog>` 和 `showModal()`。
- 弹窗以视口为参照，桌面端必须严格水平、垂直居中。
- 不允许继承页面内容容器的左偏移，不用项目网格坐标定位。
- 建议采用浏览器 dialog 居中模型，配合 `margin: auto`；动画只作用于内部 panel，不改变 dialog 的定位基准。
- 桌面端最大宽度约 960px，最大高度为 `86dvh`。
- 超出内容在弹窗内部滚动，背景页面锁定滚动并补偿滚动条宽度。
- 移动端保留安全边距，可呈接近满屏的内容面板，但不能超出视口。

### 7.2 可访问性

- `aria-labelledby` 关联项目标题。
- 打开后初始焦点到关闭按钮。
- 支持关闭按钮、Escape 和同源遮罩点击关闭。
- 关闭后焦点回到触发卡片；深链进入时回到项目区标题。
- 保持 `?project=<slug>` 深链与现有 History 行为。

## 10. 动效

动效只用于表达层级、反馈和状态变化：

- 身份栏、履历区与项目区进入视口时进行轻量顺序出现。
- 项目卡片在 fine pointer 下提供轻微倾斜与聚光反馈。
- 弹窗打开、切换项目和关闭时只动画内部 panel 的 `transform` 与 `opacity`。
- 弹窗定位容器本身不做偏移变换，避免再次产生视觉偏左。
- 所有动画遵守 `prefers-reduced-motion`，Reduced Motion 下直接显示最终状态。

禁止自定义鼠标、滚动劫持、强视差和无限循环装饰动画。

## 11. 深色模式

- 默认仍以 B1 明亮主题作为主要视觉。
- 跟随 `prefers-color-scheme: dark` 自动切换，不增加手动主题按钮。
- 深色模式使用深蓝灰背景、深色通透履历面板和可读的浅色正文。
- 公司 Logo 保留官方品牌色；必要时增加中性底片保证识别，不改变 Logo 颜色。
- 项目截图不做反色。
- 明暗模式均满足正文和交互控件的 WCAG AA 对比度。

## 12. 错误与降级

- 项目图片失败：显示稳定比例文字回退。
- 公司 Logo 失败：隐藏图片并保留完整公司名称。
- 不支持 `backdrop-filter`：使用不透明的雾蓝或白色表面，保持相同层级。
- JavaScript 不可用时：主页身份与履历等静态信息仍需可阅读；项目弹窗及其源码链接属于 JavaScript 增强内容，不承诺无脚本访问。
