# 沉浸式个人主页重构设计

日期：2026-09-26  
状态：用户已指定参考站并要求继续实施  
目标仓库：`aurostars/aurostars.github.io`

## 目标

以 `https://immersive-g.com/` 的空间感、浮雕材质和克制编辑排版为参考，彻底重构现有个人主页。保留董星的真实教育、实习、项目、联系方式和项目详情交互，最终通过现有 GitHub Pages 工作流发布。

本次不是逐像素复制。页面使用原创三维花园、原创构图和董星本人的内容，不使用参考站的品牌、文案、模型或媒体资源。

## 设计判断

- 页面类型：面向招聘者、产品负责人和潜在协作者的个人作品集。
- 访客模式：Experience。
- `DESIGN_VARIANCE: 9`
- `MOTION_INTENSITY: 8`
- `VISUAL_DENSITY: 3`
- 主题：全页明亮石膏白，不跟随系统深色模式。
- 字体：Source Serif 4 Variable 负责展示文字，Geist 负责界面和正文。

## 视觉世界

页面像一块会呼吸的白色植物浮雕。实时 WebGL 场景占据背景：柔软茎叶、花瓣、飞鸟和种子在浅灰石膏空间中形成深浅关系。随着滚动，镜头缓慢穿过花园，部分材质从石膏白转向冷蓝和浅绿，服务于章节转换。

界面层保持克制：

- 固定左上角为姓名标识，右上角为菜单按钮。
- 黑色细字、编辑式衬线标题、极少边框。
- 内容主要靠留白、对齐和图像比例组织，不使用通用玻璃卡片、紫色光效或三列功能卡。
- 圆角仅用于真实项目截图与项目详情弹窗，统一为 8px。

## 页面路径

1. 首屏：原创三维浮雕花园，左下显示董星及一句定位。
2. 宣言：大号衬线文字说明产品思考与独立实现能力。
3. 履历：教育与实习组成一组紧凑编辑式索引，保留全部事实。
4. 项目：六个项目使用真实截图形成错落的双列作品墙。
5. 项目详情：沿用原生 dialog、查询参数深链、焦点恢复和真实功能信息。
6. 联系：邮箱与 GitHub，作为页面收束。

## 核心交互

### 三维场景

- 使用 Three.js 程序化生成原创植物形态，不加载参考站模型。
- 指针轻微影响镜头与植物朝向。
- 使用 Motion `useScroll` 驱动场景进度，不监听原生 `window.scroll`。
- 首屏缓慢呼吸，进入正文后相机平移和拉远。
- 场景不可用时显示 CSS 浮雕静态构图，并保留全部文字内容。
- 页面隐藏、场景离开可视区、Reduced Motion 或运动稳定时停止不必要渲染。

### 菜单

- 右上菜单打开同主题全屏覆盖层。
- 链接指向首页、履历、项目和联系。
- 支持 Escape 关闭、焦点进入菜单、关闭后返回按钮。
- 移动端保持同一信息结构，不复制第二套导航。

### 项目

- 项目卡仍是单一原生按钮，点击打开现有项目详情。
- 真实截图不叠加装饰标签，项目名称和类型置于图片下方。
- 桌面为错落双列，移动端为单列。
- 详情继续支持 URL 深链、浏览器前进后退、遮罩关闭、键盘焦点循环和外部链接。

## 架构

- `src/app/page.tsx` 保持 Server Component，只组合数据和主页入口。
- `src/components/immersive/immersive-home.tsx` 管理菜单、章节结构与现有组件组合。
- `src/components/immersive/garden-scene.tsx` 是独立 Client Component，负责 Three.js 生命周期、Motion scroll progress、指针和降级。
- `src/components/immersive/site-menu.tsx` 负责全屏菜单和焦点管理。
- 复用 `ProfileHistory`、`FeaturedCases`、`CaseDialog` 与现有内容模型。
- `src/app/globals.css` 替换旧 B1 视觉，但保留现有测试依赖的语义类名和响应式能力。

## 内容与真实性

- 保留 `portfolio.ts` 中所有教育、实习、项目和联系事实。
- 不新增客户、指标、奖项或结果。
- 首页中文案可以重新组织，但不能改变事实。
- 项目媒体继续使用仓库中的真实本地截图。

## 响应式与性能

- 验证 1440×900、1024×768、768×900、390×844 和 320×800。
- 首屏使用 `min-height: 100dvh`。
- 三维像素比上限 1.5；移动端减少几何细分和背景对象数量。
- Three.js 动态导入，静态内容先渲染。
- 图片保持固有尺寸和稳定比例，避免 CLS。
- 无横向溢出，正文不被固定导航遮挡。
