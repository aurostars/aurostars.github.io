# 个人主页内容重排设计

**日期：** 2026-09-11  
**状态：** 已确认，待实现

## 目标

在不改变现有明亮、紧凑视觉方向的前提下，让首页更像自然的个人主页：首屏表达个人态度并直接呈现教育与实习经历；个人项目仍是主体；页面底部只承担联系转化。

## 页面结构

首页按以下顺序组织：

1. Hero：个人表达、简介、项目入口、教育与实习经历
2. 个人项目：四个项目摘要及按需展开详情
3. 联系：欢迎联系、邮箱、GitHub

原底部“经历与能力”整合区不再显示，避免与 Hero 重复。

## Hero

### 左栏

- 保留标签“AI 产品经理”。
- 一级标题改为“认真体验，持续表达”。
- 保留现有简介“把 AI 能力接入真实工作流，用产品与数据持续验证价值。”。
- 主按钮文案改为“查看项目”，继续跳转到 `#cases`。

### 右栏

删除三张项目界面预览图片，改为紧凑信息索引：

- 教育：完整展示两条教育信息。
- 实习经历：完整展示五条经历，每条保持单行信息密度，包含时间、组织、角色和一句经历摘要。
- 使用清晰分隔线和弱化的时间文字，不使用独立卡片堆叠，不增加阴影或装饰图片。
- 保留 `#experience` 锚点，顶部导航中的“经历”仍可跳转到 Hero 右栏。

### 响应式

- 桌面端保持左右双栏。
- 移动端按左栏介绍、教育、实习经历的顺序单列显示。
- 最窄 320px 下经历允许内容自然换行，不产生水平滚动。

## 个人项目

- 区块标题由“代表案例”改为“个人项目”。
- 删除标题下方“先快速浏览项目，再展开查看完整判断与工作流程。”说明文字。
- 保留现有 2×2 摘要网格、单详情展开、5/6 项自然扩展及项目详情内容。
- 每张摘要卡使用稳定的内部网格，让“展开详情”和“查看源码”固定在卡片底部并保持同一水平基线。

## 联系

- 删除底部重复的经历、教育和能力内容。
- 页面底部只保留联系区。
- 标题改为“欢迎联系～”。
- 联系方式仍且仅包含邮箱与 GitHub。
- 保留 `#contact` 锚点和现有外链安全属性。

## 组件调整

- `Hero` 接收并渲染 `education` 与 `experiences`，不再依赖案例媒体。
- 新增或提取一个专门的 Hero 资料索引组件，负责教育和实习内容，避免把数据展示细节全部塞进 `Hero`。
- `Home` 只组合 `Hero`、`FeaturedCases` 和底部联系区。
- 复用现有联系组件；不保留仅为旧底部 Profile 布局服务的页面组合。

## 验收标准

- 首页 H1 精确为“认真体验，持续表达”。
- Hero 中不再出现“个人项目界面预览”图片组。
- Hero 完整展示 2 条教育信息与 5 条实习经历，并保留 `#experience`。
- 个人项目区标题精确为“个人项目”，且不存在原说明文案。
- 四张项目卡片的操作区固定在卡片底部；同一行操作链接视觉基线一致。
- 页面底部只出现“欢迎联系～”、邮箱和 GitHub，不重复显示经历、教育或能力。
- 桌面和 320px 移动端无横向溢出。
- 现有单详情展开、键盘操作、ARIA、reduced-motion 和静态导出能力不回归。
- 测试、lint、类型检查、生产构建和 `git diff --check` 全部通过。
