# 个人主页流体动效设计

**日期：** 2026-09-12  
**状态：** 已确认，待实现

## 设计判断

这是一个面向访客与招聘者的个人作品集，现有页面采用明亮、克制、紧凑的信息语言。动效应帮助建立阅读顺序、强化操作反馈和增加页面生命力，不应遮盖项目内容或改变信息结构。

- `DESIGN_VARIANCE: 6`
- `MOTION_INTENSITY: 6`
- `VISUAL_DENSITY: 7`
- 模式：Redesign - Preserve
- 视觉基础：现有 Geist 字体、冷灰背景、单一蓝色强调色、统一圆角体系
- 页面主题：保持现有浅色主题，本轮不静默引入深色模式

## 动效原则

每个动效必须承担至少一个明确目的：

- 层级：让访客先看到标题，再看到简介和入口。
- 叙事：让教育、经历和项目按页面阅读顺序进入。
- 反馈：让鼠标悬停、点击和详情展开有清晰回应。
- 状态变化：让案例详情的出现和消失可被理解。

不添加仅为“看起来更酷”的循环动画。

## 技术架构

### 动效库

新增 `motion` 依赖，并从 `motion/react` 使用：

- `motion`
- `AnimatePresence`
- `useMotionValue`
- `useSpring`
- `useTransform`
- `useReducedMotion`

不引入 GSAP、Three.js 或第二套动画库。

### 组件边界

静态结构继续由现有 Server Components 负责。连续输入与视口交互隔离在小型 Client Components 中：

1. `Reveal`：负责一次性视口进入动画。
2. `StaggerGroup` / `StaggerItem`：负责 Hero 文案、经历行和项目卡片的顺序进入。
3. `TiltCard`：负责项目卡片的鼠标倾斜与局部高光。
4. `FeaturedCases`：继续负责单项展开状态，并增加详情的进入、退出和布局过渡。

连续鼠标坐标只写入 Motion Values，不写入 React state，不触发每帧 React 重渲染。

## 首屏进入动画

Hero 左栏首次加载时按以下顺序进入：

1. “AI 产品经理”标签
2. “认真体验，持续表达”标题
3. 简介
4. “查看项目”按钮

参数：

- 初始位移：`y: 20px`
- 初始透明度：`opacity: 0`
- 单项时长：`0.6s`
- 错峰间隔：`0.07s`
- 缓动：`[0.16, 1, 0.3, 1]`
- 动画只执行一次

Hero 右栏教育与经历随后进入：

- 教育区作为一个整体淡入上移。
- 5 条实习经历按 `0.05s` 间隔依次出现。
- 不改变 Hero 高度，不等待动画完成才显示布局。

## 滚动进入动画

### 个人项目

- 区块标题进入视口时淡入上移。
- 项目卡片按 DOM 顺序错峰进入。
- 每张卡片只在首次进入时动画，返回页面上方后不重复播放。
- 触发阈值约为元素进入视口 25%。
- 初始位移不超过 `24px`，避免“飞入”感。

### 联系区

- 联系区整体进行一次简洁的 `opacity + y` 进入。
- 不添加循环呼吸、闪烁或磁吸效果。

### 滚动边界

- 不劫持原生滚动。
- 不使用横向滚动、固定堆叠、视差背景或滚动进度条。
- 不监听 `window.scroll`。

## 项目卡片鼠标效果

仅在同时满足 `hover: hover` 与 `pointer: fine` 的设备启用。

### 倾斜

- 鼠标相对卡片中心计算 `rotateX` 与 `rotateY`。
- 最大旋转角度为 `3deg`。
- 悬停时最多上移 `4px`，不改变文档流。
- 离开后使用弹性参数自然归位：`stiffness` 约 180，`damping` 约 22。
- 使用 `transform-style: preserve-3d`，但不制造夸张景深。

### 局部高光

- 卡片内部使用一个 `pointer-events: none` 的高光层。
- 高光中心跟随 Motion Values 或 CSS 变量更新。
- 高光使用现有蓝色强调色的低透明度版本，半径约 `220px`。
- 不使用外发光、霓虹边缘或持续动画。

### 交互安全

- 卡片内部按钮与链接保持原生点击、焦点和键盘行为。
- 倾斜容器不拦截事件，不改变 tab 顺序。
- 触屏设备保持静态卡片。

## 链接与按钮反馈

- 导航链接、主 CTA、案例操作按钮和联系链接统一使用 `180-240ms` 的位移/颜色过渡。
- 悬停时仅产生 `translateY(-1px)` 或轻微颜色变化。
- 按下时使用 `translateY(1px)` 或 `scale(0.98)`。
- 焦点样式继续由现有 `:focus-visible` 规则提供，不被 hover 效果覆盖。
- 不制作自定义鼠标指针或磁吸按钮。

## 案例详情过渡

- 保留现有“同一时间只展开一个详情”的状态逻辑。
- 使用 `AnimatePresence` 为详情增加进入与退出：
  - `opacity: 0 -> 1`
  - `y: 12px -> 0`
  - 时长约 `0.35s`
- 使用布局动画让卡片行与后续内容平滑重新排布。
- 不动画高度数值，不手写 `scrollHeight` 计算。
- 展开后详情仍位于所选卡片所在行之后，桌面跨两列，移动端紧随卡片。

## Reduced Motion

当 `prefers-reduced-motion: reduce` 时：

- 所有进入动画直接显示最终状态。
- 卡片倾斜与局部高光停用。
- 详情立即出现和消失，不使用位移或透明度过渡。
- 原生平滑滚动关闭。
- 页面功能、内容顺序与焦点行为不变。

该降级必须通过 `useReducedMotion` 和现有 CSS 媒体查询双重保护。

## 性能约束

- Motion 自动动效只动画 `transform` 与 `opacity`；不得通过 Motion 动画布局或颜色属性。B 方案允许 hover/focus 状态使用约 `200ms` 的 `color`、`background-color`、`border-color` CSS transition。
- 不使用 React state 保存连续鼠标或滚动值。
- 不使用 `window.addEventListener("scroll", ...)`。
- `will-change` 只应用于当前悬停或正在进入的元素。
- 动效 Client Components 保持小型并及时清理事件与 Motion Values。
- 不改变图片加载策略，不增加首屏大图。
- 目标：桌面和移动端无明显掉帧，静态导出继续可用。

## 响应式行为

- 1440px、1024px、768px：完整启用滚动进入；仅精细指针设备启用卡片倾斜。
- 390px、320px：停用卡片倾斜，保留轻量进入动画与详情过渡。
- 动画不增加水平溢出，不改变当前断点结构或页面高度。

## 测试与验收

### 自动测试

- 新动效组件在 reduced motion 下渲染静态最终状态。
- `TiltCard` 不使用 React state 跟踪 pointer 坐标。
- 项目卡片仍保留原生按钮、链接、ARIA 和单项展开逻辑。
- 详情退出后从 DOM 移除，切换项目时仍只有一个详情。
- 不存在 `window.addEventListener("scroll"`。

### 真实浏览器

在 1440、768、390、320 宽度验证：

- Hero 进入顺序自然，CTA 首屏可见。
- 项目区和联系区首次滚动进入，不重复闪烁。
- 精细指针下卡片倾斜不超过 3deg，离开后归位。
- 卡片内部按钮和链接可点击、可聚焦。
- 展开/切换/收起详情动画不破坏布局。
- reduced motion 模式无位移、倾斜和延迟。
- 320px 无横向滚动。
- 图片全部加载，控制台无运行时错误。

## 明确不做

- 自定义鼠标指针
- 鼠标图片拖尾
- 视差背景
- 滚动劫持
- 横向滚动页面
- 无限 marquee
- 自动循环动画
- GSAP 或 Three.js
- 深色模式改造
- 内容、配色、字体、导航与页面结构重构
